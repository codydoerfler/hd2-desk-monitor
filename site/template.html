What you see

One glance and you know where the war stands

No menus, no tapping through screens. Every card is built around the target planet's own biome, with the numbers that matter set over it.

The order

What High Command wants

The objective, the medals riding on it, and exactly how long is left. The countdown ticks every second.

The planet

How close it is to falling

Which world, which sector, who holds it now, and how far the liberation has actually got — against the enemy pushing the other way.

The pace

Whether you're winning it

How many divers are on the ground, and whether their push per hour is beating the enemy's regen. The difference between a planet you'll take and one you won't.

It's never idle

When an order names several planets, the display cycles through them. When there is no order at all, it shows the five busiest liberation campaigns in the galaxy instead — so there is always a war on the screen while there is a war on.

When it matters

It looks up and tells you

Most of the time it is a quiet dashboard you read out of the corner of your eye. Twice per order it takes the whole panel — and plays a clip through the speaker so you hear it from the other side of the room.

Then it leaves you alone

Nothing to maintain

It is a finished object, not a project you keep tending. Set it up once and it looks after itself from there.

Setup

Plug it in, join it to your WiFi from your phone once. That is the entire setup.

Updates

New firmware arrives over the internet on its own. A cable is only ever needed for the very first flash.

Outages

Lost the connection? The last good data stays up, quietly marked stale. Stale beats blank.

Touch

Swipe to page through planets by hand, tap to dismiss an alert. It keeps cycling on its own either way.

Major Order Desk Monitor

An unofficial fan project by Cody Doerfler. Built on an ESP32 with a 4″ panel, reading the community Helldivers 2 API. If you want the pinout, the partition table and the reason the touch driver had to be rewritten, it's all in the README on GitHub — along with everything you'd need to build one.

Built on

  • helldivers-2/api — the war data
  • Bodmer/TFT_eSPI — the display
  • Firmware releases
